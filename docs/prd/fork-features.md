Выборочный план переноса пользовательских возможностей из двух исследованных Meetily-форков. Каждая задача ограничена одной проверяемой возможностью и не означает, что код донора можно перенести целиком.

## Вопросы по встрече и решение о Claude Code

В деталях встречи поле вопросов использует выбранную в настройках модель и
показывает local/network provider. Для сетевого запроса требуется отдельное
согласие, которое сбрасывается при изменении настроек. Ответ содержит цитаты и
ссылки на реплики выбранной встречи; при недостатке данных это указано явно.
Соседние встречи не включаются; слишком большой контекст отклоняется без
обрезки. Отменить можно текущую генерацию. Проверенная реализация FEAT-100/101
находится в рабочем main без нового коммита. На трёх контролируемых вопросах
реальная Gemma 4 E2B CPU подтвердила факты выбранной встречи и отказалась
выдумывать бюджет или факт из соседней встречи. Это ограниченная локальная
приёмка, а не гарантия достоверности любых ответов; цитаты следует проверять.
[Контракт и проверки](../fork/meeting-questions-2026-10-02.md).

Отдельный Claude Code CLI в текущий план не включается: исследование FEAT-117
закончено решением NO_ADOPT, условный прототип FEAT-118 — N/A. Текущий Claude API
сохраняется. [Причина, текстовый формат и источники](../fork/claude-code-provider-decision-2026-10-02.md)
не являются доказательством выполненного CLI-прототипа.

## Поиск по видимым данным встречи

Поле поиска в боковой панели находит название, расшифровку и видимый текст
итогов. Результат показывает встречу, источник, время и фрагмент; нажмите его,
чтобы открыть встречу или соответствующую реплику, в том числе после первой
страницы. Скрытые переводы и внутренний JSON не участвуют в индексе. После
изменения текст обновляется в поиске, а удалённая встреча не возвращается при
повторном открытии базы. [Приёмка текущего main](../fork/meeting-search-acceptance-2026-10-02.md)
подтверждена на временной SQLite и frontend с тестовым IPC; installed `.app`
и release-проверки остаются отдельными.

Сквозной сценарий в macOS-приложении: настроить словарь и шаблон → записать встречу → задать ручное название → получить автоматические итоги → перезапустить приложение → повторить обработку.
