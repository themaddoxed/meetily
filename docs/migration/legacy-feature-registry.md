## Safe migration waves

Within every wave, migrate only one row at a time on one `migrate/*` branch. Record the verified destination before starting the next row.

2. **Theme foundation:** semantic theme and summary prompt, then the updated palette and native appearance synchronization.

6. **Reliability and privacy:** interrupted-meeting recovery, then analytics user-agent removal.

8. **Transcription policy:** evaluate the disable-live-transcription slice, then queue behavior, then toast consolidation. Import/retranscription stays as the verified baseline.
9. **Native streaming:** migrate the committed Whisper streaming foundation at `6ac4831`, then the preserved committed review handoff at `3a8e9ee`; review the handoff's broader diff and deleted historical planning paths before applying one copy of the audio verification stabilization patch.
