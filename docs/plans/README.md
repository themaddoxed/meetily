Перенесённые документы от 2–4 октября сохранены без изменения байтов.
Версии `v2`, `v3`, `v4` — последовательность уточнений, а не автоматическое
доказательство принятия или реализации. Прочитать связанное ревью в
`docs/reviews/<topic>/` и текущую карточку в `docs/prd/`.

Исторические root-relative пути внутри этих документов переводятся через
[таблицу перемещений](../development/evidence/2026-10-18-structure-moves.json).
Старые планы со стабильными путями находятся в [docs/superpowers](../superpowers/README.md).
Новый план сохранять как `docs/plans/<topic>/YYYY-MM-DD-<task-or-purpose>.md`;
фиксировать task ID, base, scope, критерии проверки и ограничения, не дублируя backlog.
