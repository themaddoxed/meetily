# Стабильные fork-материалы

[Полный индекс](../../INDEX.md) · [текущий порядок](../development/execution-order.md)

Здесь сохранены intake, baseline, старые планы исполнения и отчёты, на которые
ссылаются существующие документы. `evidence/` и `migration-snapshot/` сохраняют
исходные байты и пути. Даты, commits, условия и ограничения каждого результата
обязательны при его использовании; эта папка не является текущей очередью задач.

Октябрьские SPEC/QUALITY ревью перенесены в [docs/reviews](../reviews/README.md),
октябрьские планы из superpowers — в [docs/plans](../plans/README.md).
Прежние пути разрешаются через [manifest](../development/evidence/2026-10-18-structure-moves.json).

[execution history](execution-plan-2026-09-22.md),

[frozen migration registry](migration-registry.md),
