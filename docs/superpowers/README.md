# Исторические планы и спецификации

[Полный индекс](../../INDEX.md) · [актуальная навигация по планам](../plans/README.md)

`plans/` и `specs/` сохраняют материалы июня–августа и их первоначальные пути.
Некоторые из них читают migration verifier-скрипты. Перемещение этих документов
требовало бы изменения контракта проверки, поэтому они оставлены как исторические
опорные документы. Наличие текста не означает, что задача до сих пор открыта:
текущий статус находится в `docs/prd/` и связанном реестре переноса.

23 октябрьских плана и census перенесены в `docs/plans/<topic>/` с сохранением
байтов. Для прежних ссылок использовать
[таблицу перемещений](../development/evidence/2026-10-18-structure-moves.json).
Новые планы создавать в `docs/plans/`, новые ревью — в `docs/reviews/`.
