# Public documentation assets

are retained in this privacy snapshot. Twelve UI screenshots containing meeting
text or local-machine context and three animated demos were omitted. Original
assets are preserved in the private local archive.

`HighLevel.jpg` describes the legacy FastAPI/vector-database design;
`Diagram-High level architecture diagram.jpg` also describes Electron. These
are historical illustrations, not the current Tauri/Rust product architecture.
Current behavior is defined by source/configuration and `docs/testing.md`.
